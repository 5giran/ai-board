# 최종 제출 체크리스트

## 프로그램 소스

- [ ] 로컬에서 `pnpm install` 후 실행 가능하다.
- [ ] `.env.example`이 최신이다.
- [ ] DB migration 실행 방법이 README에 있다.
- [ ] 불필요한 빌드 산출물이 포함되지 않았다.

## README.md

- [ ] 프로젝트 개요가 있다.
- [ ] 주요 구현 기능이 있다.
- [ ] 전체 아키텍처 구조가 있다.
- [ ] RAG 기능의 기술, 데이터 흐름, 아키텍처가 있다.
- [ ] MCP 기능의 서버 구조, JSON-RPC 처리, 외부 서비스 연동 설명이 있다.
- [ ] Agent 기능의 추론 루프, 도구 호출, 상태 관리, 예외 처리가 있다.
- [ ] 실행 방법과 데모 계정 또는 테스트 방법이 있다.

## 데모

- [ ] 스크린샷이 1개 이상 있다.
- [ ] 회원가입/로그인 흐름을 보여줄 수 있다.
- [ ] 게시글 CRUD와 댓글을 보여줄 수 있다.
- [ ] RAG, MCP, Agent 기능을 각각 시연할 수 있다.

## 회고

- [ ] 잘 된 점을 구체적으로 썼다.
- [ ] 한계점을 숨기지 않고 썼다.
- [ ] 개선 아이디어가 실제 다음 작업으로 이어진다.
- [ ] React, NestJS, AI 기능에서 각각 배운 점을 분리해서 썼다.
