# Extendly Product Docs

이 디렉터리는 Extendly 구현 기준 문서를 모아 둡니다.

- [extendly_spec.md](./extendly_spec.md): 로직, 데이터 모델, API, AI 기능의 source of truth
- [extendly_codex_ui_spec.md](./extendly_codex_ui_spec.md): UI/UX, 레이아웃, 디자인 토큰, 문구 기준
- [../wireframes/extendly_wireframes.html](../wireframes/extendly_wireframes.html): 화면 구조 참고용 HTML 와이어프레임
- [../wireframes/extendly_reference.html](../wireframes/extendly_reference.html): 최종 UI 구현 시 대조할 정적 HTML 레퍼런스

구현 중 기준이 충돌하면 로직/데이터/API는 제품 명세를, 화면 외형과 문구는 UI/UX 구현 지시서를 우선합니다.
HTML 파일은 요구사항을 대체하지 않고, 문서 기준을 실제 화면으로 해석할 때 확인하는 보조 레퍼런스입니다.
