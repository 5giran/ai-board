# 챕터 진행 기록 템플릿

아래 내용을 챕터마다 복사해서 채웁니다.

```md
# Chapter NN 진행 기록

## 오늘 만든 것

- 

## 이해한 개념

- 

## 레퍼런스 체크

- [ ] 제품 명세: `docs/product/extendly_spec.md`
- [ ] UI/UX 지시서: `docs/product/extendly_codex_ui_spec.md`
- [ ] 와이어프레임: `docs/wireframes/extendly_wireframes.html`
- [ ] UI 레퍼런스 HTML: `docs/wireframes/extendly_reference.html`
- [ ] 이번 챕터 구현과 충돌하는 기준이 없었는지 확인

## 헷갈린 부분

- 

## 내가 내린 설계 결정

- 

## 실행한 검증

- [ ] 

## 에러와 해결 과정

- 

## 다음에 물어볼 것

- 

## 회고 한 문장

```

## 공유할 때의 팁

- 파일 이름만 말하지 말고 역할을 함께 설명합니다.
- 에러는 마지막 줄만 공유하지 말고 원인으로 보이는 부분도 함께 적습니다.
- “잘 모르겠다”보다 “A와 B 중 무엇이 맞는지 모르겠다”라고 쓰면 리뷰가 빨라집니다.
